# ModuSoft 로고 파일

명함·문서·발표 자료에 쓰는 원본이다. 사이트가 쓰는 파일은 `assets/brand/` 에 따로 있다.

| 파일 | 쓰는 곳 |
|---|---|
| `modusoft-logo` | 가로형 — 기본 |
| `modusoft-logo-stacked` | 세로형 — 정사각형에 가까운 자리 (명함 뒷면 가운데 등) |
| `modusoft-mark` | 심볼만 — 가로형이 120px(인쇄 약 20mm)보다 좁아질 때 |
| `modusoft-app-icon` | 잉크 바탕 아이콘 — 프로필 사진, 앱 아이콘 자리 |
| `*-inverse` | 어두운 바탕 위 (흰 로고) |

- **인쇄에는 `svg/` 를 쓴다.** 글자까지 모두 도형이라 폰트 없이 어디서 열어도 같다.
  인쇄소가 AI/PDF 를 원하면 SVG 를 일러스트레이터·피그마에서 열어 그대로 내보내면 된다.
- `png/` 는 투명 배경이다. 가로형 2400px, 심볼·아이콘 2048px (300dpi 기준 약 20cm·17cm).

## 규칙

- 여백: 로고 둘레에 타일 한 칸의 절반 이상을 비운다.
- 최소 크기: 가로형 너비 120px(인쇄 20mm). 그보다 좁으면 심볼만 쓴다.
- 색은 바꾸지 않는다. 늘이거나 기울이거나 그림자를 넣지 않는다.

| 이름 | 값 | 쓰임 |
|---|---|---|
| 잉크 | `#211D1A` | 심볼, ModuSoft |
| 보조 | `#79716B` | 모두소프트 (어두운 바탕에서는 `#A8A29E`) |
| 종이 | `#FCFCFB` | 어두운 바탕 위 로고 |

## 만든 방식

- 심볼: 64칸 격자 — 여백 6 · 타일 24 · 간격 4, 모서리 7, 빈 칸 선 4.
- ModuSoft: Sora Bold, 자간 −3% (f·t 사이만 +4.5%).
- 모두소프트: Pretendard Bold, 자간 +2%.
- 두 글꼴 모두 SIL Open Font License 라 로고에 써도 된다.
