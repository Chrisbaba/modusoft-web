개인정보처리방침 — 점점

시행일 2026년 9월 16일 · 적용 대상: 점점 iOS · Android 앱 v1.0
점점은 어떤 개인정보도 수집하지 않습니다.
앱에 입력한 모든 기록은 사용자의 기기 안에만 저장되며, 어디로도 전송되지 않습니다.

1. 수집하는 정보

없습니다

점점은 회원가입이 없고, 계정이 없으며, 서버가 없습니다. 이름·이메일·전화번호·기기 식별자·위치·연락처를 수집하지 않습니다.

2. 앱에 저장되는 정보

사용자가 직접 입력한 다음 내용이 기기 내부 저장소에만 저장됩니다.

  • 두통 기록 (시각, 강도, 부위, 지속시간, 메모)
  • 기상·취침 시각
  • 식사 내용
  • 특이사항, 약 복용 메모
  • 주간 리포트에 인쇄할 이름 (사용자가 설정에 직접 적은 경우에만)

이 정보는 개발자를 포함한 누구에게도 전송되지 않습니다. 개발자는 이 정보를 볼 수 없습니다.

3. 제3자 제공 및 외부 전송

없습니다

점점에는 분석 도구, 광고 네트워크, 크래시 리포터가 포함되어 있지 않습니다. 앱은 네트워크 통신을 하지 않으며, 비행기 모드에서도 모든 기능이 동작합니다. Android 버전은 인터넷 권한 자체를 갖지 않습니다.

4. 데이터 백업과 내보내기

사용자가 설정 화면에서 직접 파일(JSON, 엑셀, PDF)로 내보낼 수 있습니다. 내보낸 파일을 어디에 저장하고 누구에게 보낼지는 전적으로 사용자가 결정합니다. 자동 클라우드 백업 기능은 제공하지 않습니다.

앱 데이터는 기기 운영체제의 자동 백업(iCloud 백업, Android 백업)에서 제외되어 있습니다. 기기를 바꿀 때는 설정 화면의 「전체 백업 (JSON)」으로 파일을 만들어 직접 옮깁니다.

5. 데이터 삭제

앱 안에서 기록을 지우거나 앱을 삭제하면 모든 기록이 함께 삭제됩니다. 개발자에게 삭제를 요청할 필요가 없습니다. 개발자가 가진 데이터가 없습니다.

6. 아동 및 미성년자

점점은 미성년자도 사용할 수 있도록 만들어졌습니다. 개인정보를 일절 수집하지 않으므로 연령과 무관하게 같은 방침이 적용됩니다.

7. 의료 고지

점점은 사용자가 입력한 내용을 정리해 보여주는 기록 도구입니다. 질병을 진단하거나 치료법을 제안하지 않으며, 의료기기가 아닙니다. 건강에 관한 판단은 의료 전문가와 상의하시기 바랍니다.

8. 알림

사용자가 켠 경우에만 하루 한 번 기기 안에서 알림을 띄웁니다. 알림은 기기의 로컬 알림 기능으로만 동작하며 외부 서버(푸시)를 사용하지 않습니다.

9. 방침 변경

이 방침이 변경되면 이 페이지에 변경 내용과 날짜를 게시합니다. 유료 기능 등으로 외부 전송이 생기는 경우에는 변경 전에 이 방침을 먼저 고칩니다.
